# FML references, code lineage and validation targets

This file is a cross-library index of the main papers and external implementations
that FML documents as methodological sources, ports, reference calculations or
comparison targets. The scope statement for each module remains authoritative:
using a method as inspiration is not the same as copying its implementation, and
agreement with a code is not by itself a physical accuracy claim.

Reference coverage last reviewed on 2026-11-13 through commit `1c32171`, following
the library-wide pass at `c03def9`. Module documentation records the actual
validation scope; adding a citation does not extend it.

## External code and data lineage

These are software used as an implementation source, fixture generator, input provider,
or comparison target. The relation varies by module; see the linked local docs before
interpreting a test as a validation claim.

- Boltzmann and transfer spectra: [CLASS](https://github.com/lesgourg/class_public), [CAMB](https://github.com/cmbant/CAMB), [hi_class](https://github.com/miguelzuma/hi_class_public), CLASS_EDE, and [axionCAMB](https://github.com/dgrin1/axionCAMB).
- Nonlinear power: CAMB `mead2016`/`mead2020`; CLASS Halofit/Bird; [ACTio-ReACTio](https://github.com/nebblu/ACTio-ReACTio).
- Simulation/timestepping: L-PICOLA/MG-PICOLA for matched cosmological PM/COLA comparisons.
- Perturbation theory: [FAST-PT](https://github.com/JoeMcEwen/FAST-PT) stored outputs and [velocileptors](https://github.com/sfschen/velocileptors) reference calculations/ported components.
- Halo and void methods: pinned [ROCKSTAR](https://github.com/yt-project/rockstar) comparison; [Revolver](https://github.com/seshnadathur/Revolver) method/code reference.
- Axion nonlinear model: pinned [axionHMcode](https://github.com/SophieMLV/axionHMcode) and [axionCAMB](https://github.com/dgrin1/axionCAMB).
- Additional comparison/recipe sources: [CLASS-PT](https://github.com/Michalychforever/CLASS-PT), [pypower](https://github.com/cosmodesi/pypower), [FastPM](https://github.com/fastpm/fastpm), [Halotools](https://github.com/astropy/halotools), [SciPy](https://github.com/scipy/scipy), [PyTorch](https://github.com/pytorch/pytorch), and the [Sesame pipeline](https://github.com/renmau/Sesame_pipeline). These are not all code ports; module documentation identifies each relationship.
- Survey examples: [make_survey](https://github.com/cmcbride/make_survey).
- FFTLog lineage: [Slosar/FFTLog](https://github.com/slosar/FFTLog), [Copter](https://github.com/jwgcarlson/Copter), and mcfit-style spherical transforms.

Third-party dependencies such as FFTW, GSL and CGAL are implementation dependencies,
not algorithm citations; consult the build documentation and the projects' own citation
instructions when publishing work that uses them.
