# Frozen small-field input

These two small input fixtures are copied byte for byte from the original
fixed-IC campaign. They contain 74 half-complex coefficients (124 real degrees
of freedom), plus generator metadata. The second joint-proposal campaign uses
these exact data rather than generating a new noise realization. The data SHA256
is pinned in `../plan_joint.json`. The known physical ICs are reproduced from
the fixed band-limited counter-based seed in `Main.cpp` on every mesh.

This is a Gaussian tracer field generated by the N16/deposition48/width8 model.
It is not a discrete galaxy catalog or external challenge data. Raw chains and
figures remain outside the library.
