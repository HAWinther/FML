# Alternating field/scalar pilot (#52)

The measured gain is mixed: field-power bulk ESS per PM evaluation improves
about 2.86x, but median bulk efficiency across all features improves only 5.1%,
and median tail efficiency falls about 3.0%. The strict bulk/tail criteria still
fail. Keep this as an opt-in experiment; this pilot does not justify replacing
the default sampler or declaring calibrated posterior uncertainty.

The opt-in blocked kernel completes four chains on exactly the baseline N16/M16,
16-step target, frozen TSC data, 122 physical active coordinates and priors. It
retains the 122*A/2 Jacobian. The protocol remains 64 warmup + 128 retained draws
per chain, field mass 21, starting step .25, target acceptance .85, and jittered
4..8 leapfrog steps. Four cheap conditional slice sweeps follow each field HMC
move. The HMC RNG is 12000+chain ID; scalar RNG is 23000+chain ID.

## Correctness and review evidence

The optional kernel lives in validation code; the production HMC engine and
default joint sampler are unchanged. The default path reproduces the preceding
short states, features and predictions bit for bit. Independent numerical
quadrature agrees with 200,000 draws each for amplitude/noise conditional forms
and a narrow Gaussian near a support edge. Native checks compare scalar
conditional differences to the full joint target and test cache restoration.
A deliberately rejected-field run keeps q fixed while A,N update.

Twenty-four short native checks cover serial, 1/2/4-rank FFTW slabs, 1/2/4-rank
pencils and ASan/UBSan. Density/gradient/Jacobian and conditional/cache checks pass;
short retained states agree across backends within 2e-9. The actual 16-step
sampling target passes the same direct and finite-difference checks. Every outer
iteration asserts zero extra PM evaluations for scalar sweeps and force refresh.

The reference-density cache is restored after a rejected field trajectory.
After changing A,N, the resumed HMC potential and gradient are refreshed to the
new conditional target. RNG and adaptation state remain intact. Adaptation ends
before retained sampling. These are necessary for a correct alternating kernel.
