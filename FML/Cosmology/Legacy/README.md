# Legacy cosmology code

The original teaching Einstein-Boltzmann solver of FML (flat LCDM, no massive neutrinos; used for
https://cmb.wintherscoming.no/): `BackgroundCosmology`, `RecombinationHistory` (Saha + Peebles), `LinearPerturbations`,
`LinearPowerSpectra` and the program `EinsteinBoltzmannSolver` (CMFB). It is kept here, unchanged apart from the
include paths, until it is removed; the new solver is in the folders above (see `../EinsteinBoltzmannSolver/README.md`).
