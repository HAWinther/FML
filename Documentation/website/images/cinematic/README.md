# Cinematic illustration series

AI-generated conceptual scientific illustrations created with the built-in image_gen tool. They are not simulation outputs or quantitative predictions. Luminous matter, field colors, layer separations and scale transitions are visual metaphors. Full-resolution originals are preserved; existing Website figures are unchanged.

Open [the review gallery](index.html) for all twelve images.

Generated using the built-in `image_gen` tool. Complete final prompts and image metadata are in [prompts.json](prompts.json).
